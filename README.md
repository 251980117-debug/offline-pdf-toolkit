# Offline PDF Toolkit

Version 0.2: processing engine plus connected screens.
All document processing happens on the device.

## Requirements
- Flutter 3.47 or later (Dart 3.13 or later), required by pdfrx 2.6.6
- Android: Java 17 and Android Gradle Plugin 8.12.1 or later (required by share_plus)
- iOS 15 or later, built on macOS with Xcode

## Setup
```
cd offline_pdf_toolkit
flutter create . --platforms=android,ios --project-name offline_pdf_toolkit
rm test/widget_test.dart      # generated by flutter create, not used
flutter pub get
```
For iOS, set the deployment target to 15.0 in Xcode and in ios/Podfile.

## Run
```
flutter test                                            # unit tests, no device needed
flutter test integration_test/engine_validation_test.dart -d <device-id>
flutter run -d <device-id>                              # the app
```

## Screens
- Home: tools, privacy notice, recent files
- Merge PDFs and Organize pages: reorder by dragging, select, rotate, delete
- Extract pages and Split PDF: page ranges with live validation and a summary
- Images to PDF: order images and choose Compact, Balanced or High quality
- Result: preview, share, and save to device
- Privacy and about: what happens to files, limits, open-source licenses

## Structure
- lib/core: pure planning logic, no file access or PDF library
- lib/engine: the PDF library boundary and the safe write pipeline
- lib/app: startup services, file picking, editor state
- lib/ui: screens and dialogs
- test, integration_test: unit tests and on-device tests
- docs: frozen engine rules and the release checklist
